# Contributing

Agents write most of Isolade's code these days, so implementation is rarely the
bottleneck. What shapes the product is the thinking in front of it: what to
build, and how it should look and behave. A good idea goes further here than a
patch. So for now we take contributions as [issues] rather than pull requests.

Open one and describe the change you'd like to see. Keep it as informal as you
want. Pitch it the way you would to a coworker. If it touches the interface, get
specific about the UI and UX: where it lives, what it looks like, how it
behaves. The more of that you've worked out, the more likely we are to build it.

Please don't have an agent inflate a one-line idea into a formal spec. We'd
rather read your own two paragraphs.

[issues]: https://github.com/isolade/isolade/issues
